# 远行 · 美高成长指南

给上海中国体制内初中生和家长使用的中文美国高中申请与生活 Web 应用。默认场景：目前初二，完成中国初三后于 **2028 年秋**赴美，家庭年度预算 **超过 US$100,000**，之后计划申请美国大学。可调整入学年份及 9/10 年级路径。

## 运行

运行应用**无需安装任何依赖**，需要 Node.js 20 或更新版本：

```bash
npm start
```

在浏览器打开 **http://localhost:3000**。也可直接打开 `index.html` 阅读；推荐使用本地服务，便于存储、图片和 PWA 正常运作。

安卓手机与电脑连接同一 Wi-Fi 时：

```bash
npm start -- --host 0.0.0.0
```

终端会打印局域网地址，例如 `http://192.168.1.10:3000`，在手机 Chrome 中打开。防火墙与路由器需要允许设备互访。可通过 `--port 8080` 更改端口。预览服务器只开放应用文件，不会公开草稿备份或项目其他文件。

本地 HTTP 适合手机阅读。安卓 PWA 安装与 Service Worker 离线缓存通常要求 **HTTPS**；`localhost` 作为开发环境例外。若以后部署，把本文件夹的 `index.html`、CSS、JS、manifest 和 `assets` 部署到任意 HTTPS 静态网站即可，无需后端或数据库。本次交付没有自动公开发布。

## 第二版改进

- 家长首页优先显示最多三项未完成任务、收藏学校待核实事项；学生首页显示校园探索路线。
- 可跳过的准备档案包含英语阅读/讨论自评、兴趣和每周时间；建议说明依据，不预测录取。
- 每项家庭任务可编辑负责人、家庭目标日期及备注，与官方截止日分开。
- 每所学校有八项事实卡片：年级年龄、申请入口、考试、面试、当前日期、费用、英语支持及生活升学支持；逐项标注状态、适用年份、核对日期和来源。
- 学校详情可记下喜欢的原因、担心的问题和待询问事项，并在对比表查看。
- 手机正文加大，提供全局“大字”开关；长指南采用要点与可展开章节，记住上次阅读章节。
- 校园探索新增周末与求助学习单，并提供可以在上海完成的练习。
- 视频与导览均有中文导读、观看问题和中文替代入口；不提供未经核实的字幕。
- 勾选、收藏和家庭探索回答局部更新；文书输入立即保存，存储失败会明确提示。
- 第二版 JSON 备份兼容第一版；现有本机存储键保持不变，旧任务、收藏、草稿会保留。
- 离线更新须用户点击“保存并更新”后接管页面，不自动刷新正在编辑的草稿。

## 内容与功能

- 首页：家庭出发点、申请路径、重点学校、美高生活和本周任务。
- 认识美国高中：教学、选课、评分、AP/IB、示例作息、寄宿支持与大学衔接。
- 申请全指南：9/10 年级路线、英语和学术考试、申请材料、推荐、面试、签证及行前。
- 学校库：12 所私立寄宿学校的中文资料、所在州和城市、官方链接、排名来源、特色、适合重点研究的学生、费用与待确认事项。
- 搜索、地区/课程/英语支持筛选、收藏、最多 3 校对比及地图外链。
- 成长与活动：可从上海开始的真实项目和六个月积累路径。
- 文书工作室：学生素材、英文草稿、家长陈述、本机保存、英文词数和文字导出。
- 准备计划：18 项可勾选任务、家长/学生筛选、按目标年份生成的时间线、文本导出。
- 家庭预算计算器：可修改六项支出，对比三年/四年总预算。
- 家庭探索：5 个问题，无分数或录取预测，生成需要继续讨论的行动建议。
- 视频与资源：官方课堂视频、校园导览、项目资源和可搜索的中英术语表。
- 本机记录 JSON 备份与确认后恢复；无需账号，不上传用户草稿。
- 响应式设计、安卓底部导航、键盘快捷搜索、语义化表单、弹窗焦点管理、减少动态效果偏好和离线核心资源。

## 图片

六张照片已保存到 `assets/photos/`：两张安多佛校园实景、图书馆、学生交流、运动与学习氛围照片。校园实景分别由 Daderot 发布为公共领域、NCD2004 发布为 CC0；四张氛围图采用 Unsplash License。来源与授权依据保存在 `assets/photos/sources.json`。首页原图从约 3.4 MB 压缩至约 320 KB。

两张 Exeter 官方课堂照片继续远程引用，未确认缓存授权，不随项目离线打包。页面明确区分实景和氛围图，图片加载失败会使用本地插图。远程官方课堂图在离线时不可用，中文内容和六张本地图仍可阅读。

```bash
npm run cache:photos
```

缓存脚本跳过已有图片与未确认缓存依据的官方图片，并更新 `assets/photo-index.js`。页面根据索引直接选择本地或远程图片，避免先请求不存在的本地文件。脚本需要下载尚未存在的授权图片时才需要终端联网。

视频打开外部官方页面；上海网络与字幕可用性未实测。每项资源附有本站编写的中文导读、问题和替代内容，不是视频逐字翻译。图片引用不代表校方合作或认可。

## 资料维护

资料核对日期：**2026-10-28**。信息入口在每篇指南、学校详情和页脚“来源与使用说明”内。

- 排名数字来自 **2027 Niche 全美寄宿高中榜**，不是美国官方教育评级。未核实数字的学校不显示具体名次，不表示未上榜。
- 2028 等未来轮次的截止日尚需按当年官网复核，不把当前轮日期当作未来承诺。
- 托福内容已注明 2026 年新 1–6 分制及过渡期，学校旧制要求须向招生办确认。
- 明确注明学年的学校学费来自各校官方页面；其他费用区间为家庭规划估算，不是学校报价。
- 当前只提供私立寄宿学校的起点库，不是全美学校全集。未掌握学生个人学术、英语、年龄与兴趣，不能据此预测录取概率。
- 申请和生活建议应结合学校当年要求使用；签证等规则应查美国国务院和 DHS 官方资料。

基础文章、学校与任务在 `content.js`；第二版逐项事实、来源、授权信息和校园学习单在 `enrichment.js`。更新资料时同步维护逐项核对日期及 `sw.js` 缓存版本。新增本地图片后更新图片索引与离线资源列表。不要把学生姓名、证件号或其他个人材料硬编码到源码中。

## 验证

```bash
npm run check
npm test
```

核心逻辑测试无需依赖。DOM 交互测试使用开发依赖 jsdom，需要 Node.js 20.19+、22.13+ 或 24+；如尚未安装，运行 `npm install`。该依赖不参与应用运行，检查覆盖页面导航、筛选、收藏对比、任务、草稿、备份、家庭探索及弹窗等。测试在模拟 DOM 中运行，不等同于真实 Android 浏览器的视觉验证。

本次执行环境禁止本地端口监听（`listen EPERM`）。已通过原生电脑控制在真实 Chrome 中打开本地 HTML，检查桌面首页，并在 360、393、412 CSS 像素的 iframe 视口检查手机首页布局。浏览器扩展连接不可用；实际安卓设备、上海网络、200% 浏览器缩放及 HTTPS 下真实 Service Worker 更新流程尚未实测。离线资源、更新接管和网络错误行为另以模拟 Service Worker 测试验证，不把这些测试称作实际设备验证。

## 隐私与数据

准备档案、学校笔记、任务安排、字号与阅读位置也写入当前浏览器的 `localStorage`。清除浏览器、换设备或隐私模式可能导致丢失；使用页脚“本机数据”备份。导入前展示备份内容摘要，导出会记录最近备份时间。导出的备份可能包含文书与个人经历，请妥善保存。用户输入在渲染时转义。外部图片和链接会连接到相应第三方来源；图片若本地化，可减少外部图片请求。

浏览器未允许存储时会提示仅本次打开保留。多个设备之间不自动同步。应用没有付费、发送邮件、代交申请或自动生成文书的功能。
